# CLI

Commands:
- `marpelle list`
- `marpelle status <service>`
- `marpelle send <service> <command> [--payload '{}']`
- `marpelle register --manifest <MARPELLE.json>`
- `marpelle register --name <svc> --socket <path> [--pid <pid>] [--version <ver>]`
- `marpelle unregister <service>`
- `marpelle cleanup`
- `marpelle build <entry.py> [--manifest ...] [--onefile]`
